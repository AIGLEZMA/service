# Service

## Dynamic data

L'utilisateur pourra créer ses propres types de données (exemple: Client, Installation...) pour chaque type
l'utilisateur pourra préciser des fields (exemple: un client pourra avoir un nom (Texte), un prénom (Texte) et un numéro
de téléphone (Num de téléphone))

L'utilisateur doit aussi pouvoir créer des Dynamic data à partir d'autre Dynamic data déjà créer

### Importation des données

L'utilisateur pourra importer des données à partir des bases de données déjà établies (exemple: CSV)

#### Sources supportées:

- CSV
